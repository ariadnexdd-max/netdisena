NetDiseña

Sistema de diseño, planificación y documentación de redes informáticas

1. Configuración del proyecto

Configura los datos y genera el plano. El sistema valida las direcciones IP y construye automáticamente la topología y la tabla.

2. Plano visual de la red

El plano representa la conexión lógica propuesta. Las ubicaciones de los equipos son ilustrativas, no un plano arquitectónico a escala.

3. Tabla de direccionamiento IP

Dispositivo Dirección IP Máscara Puerta de enlace
Genera el plan para visualizar las direcciones.

4. Recursos y características

  • Topología de red: estrella.
  • Medio de transmisión: cable UTP categoría 6.
  • Equipo central: switch Gigabit de 16 puertos.
  • Conectividad: router Gigabit con Wi-Fi 6.
  • Estaciones de trabajo: cinco computadoras, según la configuración inicial.
  • Conexión individual de cada computadora al switch.
